# Smart Inventory Management System

This repository contains the Smart Inventory Management System — a small app for tracking inventory, restock alerts, and usage.

## Overview

Use this app to manage inventory items, record usage, and generate restock recommendations.

## Development

Install dependencies and run the dev server:

```
npm install
npm run dev
```

## Deployment

Deploy to your preferred hosting provider (Vercel, Netlify, etc.).

## Notes

- Configure Supabase environment variables in `.env.local`:
	- `NEXT_PUBLIC_SUPABASE_URL`
	- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
